# Что это за проект

Это **AI knowledge-base + assistant для здоровья Бьярки**.

Можно использовать для:

* анализа кормов
* отслеживания здоровья
* исследований ветеринарии
* планирования ухода
* отслеживания симптомов
* добавок и диеты

---

# Как использовать

Например в **OpenCode / Codex / Gemini CLI**:

```
analyze dog diet for senior samoyed
```

или

```
symptom: limping
```

AI будет использовать файлы из проекта.

# Очень рекомендую добавить (следующий шаг)

Можно расширить проект:

```
bjarki-health-ai/
```

и добавить:

```
vet-records
blood-tests
weight-history
symptom-log
```

AI тогда сможет:

```
detect early disease
analyze patterns
suggest prevention
```
