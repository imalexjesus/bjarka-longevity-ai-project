# Глобальный реестр лучших ресурсов о породе Самоед (Samoyed Resource Database)

Этот документ представляет собой структурированную базу данных лучших мировых и русскоязычных интернет-ресурсов, посвященных самоедским собакам. Информация разделена на языковые сегменты (русский/английский) и категоризирована по типам медиа. 

База служит справочником для быстрого поиска профессиональных данных по генеалогии, здоровью, уходу, покупкам и обучению.

### 📂 Pedigree & Health Databases (Crucial for Breeders)
| Resource Name | Link / Platform | Description & Value |
| :--- | :--- | :--- |
| **Pedigree Database: Samoyed** | [pedigreedatabase.com/samoyed/](https://www.pedigreedatabase.com/samoyed/search.html) | The largest user-contributed global database of Samoyed pedigrees. Contains test mating simulators, health test results (OFA/HD), and photos of historical ancestors. |
| **DogsFiles Samoyed Database** | [dogsfiles.com](https://www.dogsfiles.com/) | Multi-language international catalog. Used by European breeders to register litters, trace coefficients of inbreeding (COI), and display titles. |
| **SCARF (Samoyed Club of America Education & Research Foundation)** | [samoyedhealthfoundation.org](https://www.samoyedhealthfoundation.org/) | **The most critical health site for Samoyeds.** Deep scientific articles on breed-specific diseases (Samoyed Hereditary Glomerulopathy, diabetes, hip dysplasia, eye conditions). |
| **OFA (Orthopedic Foundation for Animals)** | [ofa.org](https://www.ofa.org/) | Official database for hip and elbow clearances in the US. Crucial for verifying that a Samoyed's ancestors actually passed health checks before breeding. |

1.  **[Samoyed Health Foundation (SCARF)](https://www.samoyedhealthfoundation.org/) (США)** — Главный мировой медицинский портал самоедов с глубокими научными статьями.
2.  **[Pedigree Database Samoyed](https://www.pedigreedatabase.com/samoyed/search.html) (Глобальный)** — Интерактивная база данных с возможностью построения виртуальных вязок и расчета процента инбридинга.

5.  **[DogsFiles.com](https://www.dogsfiles.com/) (ЕС/СНГ)** — Самая популярная европейская база для быстрого поиска предков конкретной собаки по кличке или номеру чипа.
